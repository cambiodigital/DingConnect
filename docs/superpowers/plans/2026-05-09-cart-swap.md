# Cart Swap and Restoration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow isolated recharges in WooCommerce without losing the user's current cart by implementing a cart swap and restoration strategy.

**Architecture:** We will hook into the `handle_add_to_cart` method to take a snapshot of the current cart if it contains non-recharge items. The cart will then be emptied and the recharge added. During checkout, an explicit cancel button will allow the user to abort the recharge and restore their original cart. A silent fallback hook on `template_redirect` will ensure the cart is restored automatically if the user navigates away from the checkout flow or successfully completes the order.

**Tech Stack:** WordPress, WooCommerce API (Session, Cart, Endpoints)

- [ ] **Step 2: Add the restoration logic methods**

Add these methods inside the `DC_Recargas_WooCommerce` class:

```php
    public function handle_cart_restoration_fallback() {
        if (!WC()->session) return;
        
        $snapshot = WC()->session->get('dc_cart_snapshot');
        if (empty($snapshot)) return;

        $is_explicit_cancel = isset($_GET['dc_cancel_recharge']) && $_GET['dc_cancel_recharge'] === '1';
        
        if (!$is_explicit_cancel) {
            // Do not restore if we are in checkout or doing wc-ajax
            if (is_checkout() || wp_doing_ajax() || isset($_GET['wc-ajax'])) {
                // Except if we are on the order-received page, the order is complete, we should restore it so they can continue shopping.
                if (is_wc_endpoint_url('order-received')) {
                    $this->restore_cart_snapshot($snapshot);
                }
                return;
            }
        }

        // Proceed to restore
        $this->restore_cart_snapshot($snapshot);

        if ($is_explicit_cancel) {
            wp_safe_redirect(wc_get_cart_url());
            exit;
        }
    }

    private function restore_cart_snapshot($snapshot) {
        if (WC()->cart) {
            WC()->cart->empty_cart();
            if (!empty($snapshot['cart'])) {
                WC()->session->set('cart', $snapshot['cart']);
            }
            if (!empty($snapshot['applied_coupons'])) {
                WC()->session->set('applied_coupons', $snapshot['applied_coupons']);
            }
            WC()->cart->calculate_totals();
        }
        WC()->session->set('dc_cart_snapshot', null);
    }
```
